# Sonicraft 多段参量均衡器（M9 EQ）用户说明书

> 适用版本：Pro-Q 式面板（1~31 段任意 · 真实对数频率轴 · 彩色节点拖拽/手绘双模 · 逐段类型 PK/LSC/HSC · 入口/出口双层实时频谱 · PEQ/GEQ 双模式 · 关键帧预设）
> 本说明书对应 UI：主界面「音效」区 → 「多段参量均衡器」面板

---

## 1. 一句话认识它

这是一台 **Pro-Q 风格的参量均衡器（PEQ）**：最多 31 段（段数任意可调），每段都能独立调**增益、中心频率、Q 值、滤波器类型**四个参数；曲线上**直接拖彩色节点**改音，也可以按老习惯手绘划线；底层挂着**处理前/处理后双层实时频谱**，EQ 做了什么一眼可见。

---

## 2. 快速上手（30 秒出声）

1. 打开音效：点「音效处理：开（应用 EQ 曲线）」
2. 在曲线上**抓住一个彩色圆点上下拖**——峰起谷落，松手即生效；
   或者点一条内置预设（如「低音增强」）
3. 不够劲 → 选一个段把增益拉高；怕削波 → 开限幅器（见第 10 节）

## 3. 界面导览（从上到下）

│    · 橙实线 = 全局精确响应           │
│    · 选中段彩色填充 = 该段单独作用   │

├────────────────────────────────────┤

**选中段** = 你最后点过/拖过的那个节点。曲线区该段竖线加深、节点放大带白芯、
峰形彩色填充；下方编辑区所有滑条跟随它。曲线上任点一个节点即可换选中段。

## 4. 曲线区怎么操作（双模手势）

| 手势 | 触发位置 | 效果 |
|---|---|---|
| **抓节点拖** | 按在彩色节点附近（±28dp 列内） | **横向拖=移动中心频率、纵向拖=改增益**（连续值），松手即持久化。GEQ 模式下频率锁定，只改增益 |
| **划线手绘** | 曲线区其他任何位置 | 划过的频段增益跟随手指（1dB 步进吸附），跳过的段自动插值——一笔画山谷/山峰 |

- 对数轴上段的横向位置就是它的真实频率：拖节点向右=频率升高，所见即所听。
- 高频段挤、低频段疏是**对数轴的正常形态**（人耳听感也是这样分区的）。
- **锁定手绘**：点「锁定手绘」后曲线区触摸穿透（滚动页面不会误改增益），
  编辑区滑条不受影响；再点一次解锁。锁定状态重启后保持。

## 5. 频谱衬底——看 EQ 实际做了什么

曲线区底部有两层实时频谱（FFT 2048 点，逐 bin 分析，42.7ms 时间窗）：

| 层 | 颜色 | 含义 |
|---|---|---|
| 下层 | **灰雾** | **EQ 前**的原声频谱——永远不变，是参照物 |
| 上层 | **青绿** | **EQ 后**的输出频谱——**跟随你的调整实时变形** |

- **两层之差 = 你的 EQ 实际作用量**：拖 60Hz +12dB，青层在 60Hz 隆起而灰层不动。
- 显示范围 -60~+6dB：大幅提升时频谱可以越过 0dB 线向上画，不会被削顶。
- 波形经平滑处理；峰值保持让瞬态峰停留片刻再落下，便于看清。
- 频谱只是参照物（衬于曲线之下），不可交互，常开。

## 6. 选中段编辑区（四个参数）

| 参数 | 范围 | 说明 |
|---|---|---|
| **Q 值** | 0.3~8 | 频带宽度（见第 8 节）。LSC/HSC 类型下不生效 |
| **类型** | PK / LSC / HSC | PK=钟形峰（常规段）；LSC=低架（某频率以下整体抬/降，修低频整段）；HSC=高架（某频率以上整体抬/降，提亮度/压刺角） |
| **增益** | ±12dB | 该段的提升/衰减量 |
| **频率** | 20Hz~20kHz | 该段中心/转折频率（对数滑条） |

**数字精确输入**：点任意标签（Q/增益/频率/段数）弹出输入框，带范围提示——
比滑条更快更准（如输入「3.5k」「-4.5」）。解析失败（非法数字）不改动，直接关闭。

---

## 7. 段数与段增删

- **段数 1~31 任意**：点「段数 N」输数字（1~31）——重置为该段数的默认平直配置
  （10/15/31 用标准档位频点表，其余段数按 20~20k 对数均分生成）。
- **＋段**：尾部加一段（频率取末两段的几何中点），平直 PK/Q=1。
- **－段**：删除当前选中段（至少保留 1 段）。
- **档位快捷键 10/15/31**：一键切标准档，**各档独立记忆**（增益/Q/频率/类型全套），
  互不覆盖；自定义段数同样按段数独立记忆。
- 首次从旧版本升级：低音/高音滑条的值会自动并入 10 段模式的首尾频点。

## 8. Q 值——从大笔刷到手术刀

Q 控制这段 EQ 影响的**频带宽度**：

| Q | 手感 | 听感 | 典型用途 |
|---|---|---|---|
| 0.3~0.7 | 大笔刷 | 整体音色染色：宽提升=温暖/浑厚，宽衰减=晦暗 | 风格化 |
| 1~1.5 | 常规 | 所见即所得，影响约 ±1 个八度 | 人声凸出、低频收紧（90% 场景） |
| 2~4 | 精修 | 突出单一元素：3.5kHz 窄提让军鼓「啪」地立起来 | 元素凸出 |
| 6~8 | 手术刀 | 干掉具体问题：耳机刺点、驻波、啸叫 | **扫频-陷波**（见下） |

**高 Q 的代价**：滤波器「振铃」变长——低频段高 Q 提升会把鼓点调出「嗡嗡」声。
**低频慎用高 Q 提升；高频窄衰减（陷波）则无此顾虑。**
**LSC/HSC（shelf）的 Q 不参与成形**（固定最大平坦口径），显示提示「Q 不生效」。

**扫频-陷波四步法**（修耳机刺点的神器）：
1. 选一个 Q=8 的段，增益先拉到 +6dB
2. 拖「频率」滑条来回扫，听到「嗡/刺」最明显的位置 = 问题点
3. 把增益翻成 −6dB（甚至更低）
4. 微调 Q 收窄陷波宽度，完工

---

## 9. 主曲线与选中段填充

- **橙实线**：全部段级联后的**精确合成响应**（含每段 Q/类型与邻带互作）——
  这就是「耳朵真正听到的」，没有第二种解释。拖任何参数它实时变形。
- **选中段彩色填充**：当前选中段单独作用的峰形（半透明），看清「这一段自己
  在干什么」——与整条曲线的叠加分清「单段贡献」与「级联结果」。
- 级联互作是物理现象：相邻段互相「抢」增益，单段拉满 +12 的合成峰通常低于
  +12——以橙实线为准。

## 10. PEQ / GEQ 双模式

「模式」按钮在两种图形模式间切换：

| | **参量 PEQ**（默认） | **图示 GEQ** |
|---|---|---|
| 每段增益 | 可调 | 可调 |
| 每段 Q 值 | 可调（0.3~8） | **锁定 1.0**（隐藏编辑区） |
| 每段频率 | 可调 | **锁定档位表值**（隐藏编辑区） |
| 节点拖拽 | 频率+增益 | 仅增益 |
| 适合 | 精修：扫频-陷波、修耳机频响 | 快调：像传统图示均衡器一样拖 |

- **切换警告**：切到 GEQ 会把所有段的 Q 归 1.0、频率归档位表值、类型归 PK
  （**立即持久化、不可恢复**）——弹确认框，想清楚再点「继续切换」；
  GEQ→PEQ 无损，直接切。
- 两模式共用一条曲线与预设；模式重启后保持。

---

## 11. 防削波

1. 多段同时大提升（+10dB 以上）时，留意频谱青层是否顶到 +6dB 附近——
   顶格=输出接近满幅；
2. **真峰值限幅器建议常开**（限幅器开关），作为最后防线（EQ 后还有压缩/限幅兜底）；
3. 出现「啪啪」爆音：先降低最大提升段的增益，再查是否有段顶在 ±12。

> 注：旧版的「总增益（Preamp）」滑条已从界面移除。AutoEq 导入的 preamp 仍自动
> 生效（内部通道），大提升场景靠限幅器兜底。

## 12. AutoEq 耳机修正（粘贴导入）

1. 在 autoeq.app 搜你的耳机 → 进结果页 → 复制 ParametricEQ.txt 全文
2. 面板底部「粘贴导入」→ 粘贴 → 应用
3. 段数自动精确匹配修正所需的滤波器数量（1~31 段），逐段频率/增益/Q/类型
   （含 shelf）全部导入，preamp 一并设置
4. 满意后「保存当前」存成预设，一副耳机一条

## 13. 预设

**内置 10 条**（点击即应用，自动适配当前段数）：
平直 · 低音增强 · 低音减弱 · 流行 · 古典 · 人声 · 摇滚 · 电子 · 爵士 · 明亮

**自定义预设（关键帧）**：
- 「保存当前」→ 输入名字（留空自动命名「预设 N」）→ 存下**完整快照**
  （段数 + 全部增益 + Q + 频率 + 类型）
- 点自定义条目 = 应用（跨段数模式完整恢复）；点「×」= 删除
- 保存在本机，重启不丢

**建议玩法**：一副耳机存一条「耳机名」预设（扫频-陷波修完频响后保存），
换耳机一键切换。

## 14. 常见问题

**Q：打开音效没声音？**
A：先关音效确认原声正常 → 检查是否有段异常（点「平直」预设复位）→ 查限幅器/压缩设置。本版本内置三层数值防护，正常操作不会「开 EQ 即无声」。

**Q：拖节点时曲线怎么不圆滑？**
A：节点拖的是「该段参数」，橙实线是精确级联响应——段间互作会让合成峰略低于单段设定，这是物理（见第 9 节）。

**Q：GEQ 模式下拖节点只改增益、频率不动？**
A：设计如此。GEQ 锁定频率与 Q，节点只负责增益；要动频率切回 PEQ（注意切换的归位警告）。

**Q：LSC/HSC 段拖 Q 滑条没反应？**
A：设计如此。shelf 类型的形状由固定最大平坦口径决定，Q 不参与（界面有提示）。

**Q：频谱的灰层和青层重叠看不清？**
A：灰=EQ 前参照物，青=EQ 后。想单独看 EQ 的作用量：调大该段增益，看青层相对灰层的隆起/塌陷幅度。

**Q：自定义段数（如 7 段）的频点和标准档不一样？**
A：设计如此。非 10/15/31 的段数按 20~20k 对数均分生成默认频点；±段/拖节点可再自由调整。

**Q：锁定手绘后还能误改吗？**
A：曲线区完全穿透（连滚动都不误触）；编辑区滑条与预设按钮仍可用——锁的是「画」，不锁「调」。
