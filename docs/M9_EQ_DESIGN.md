# M9 多段 EQ 设计方案（图形墙 + 专家页 + 预设 + 频响曲线）

> 2026-10-28 立项，用户拍板：两者并存 / 15 段（2/3 倍频程 ISO）/ 内置+自定义预设 / 频响曲线可视化。
> 参照：wecho IIR 均衡器（配置串驱动）；现有 ParametricEqNode（M4a，10 段 peaking 固定 Q）为基座。

## 1. 目标与现状

现状：`ParametricEqNode`（core/dsp）10 段 peaking（31Hz~16kHz 倍频程近似），固定频点固定
Q=1.0，仅增益可调（param_id 0..9 → 增益 dB），30ms 一阶斜坡防爆音已就位；链位 index 2
（Balance 之后）。Kotlin 端 EqParamIds 与之对齐，UI 10 竖滑条。

目标：15 段图形滑条墙（快调）+ 专家页（每段 freq/Q/gain 全参量）+ 内置/自定义预设 +
实时频响曲线可视化；预设互通（图形页与专家页同一 45 参数据源）。

## 2. Native 设计（parametric_eq.hpp 改造）

### 2.1 频点（15 段，2/3 倍频程）
25 / 40 / 63 / 100 / 160 / 250 / 400 / 630 / 1000 / 1600 / 2500 / 4000 / 6300 / 10000 / 16000 Hz
（1.6 倍步进 ≈ 0.68 oct，覆盖 25Hz~16kHz；业界 15 段图形 EQ 惯例）

### 2.2 参数空间（45 参，param_id 重排）
- [0, 15)   ：每段增益（dB，±12）
- [15, 30)  ：每段 Q（0.3 ~ 8.0，默认 1.0）
- [30, 45)  ：每段中心频率（Hz，对数域 20~20000 限幅，默认上表）

**兼容迁移**（关键）：旧 param_id 0..9 增益语义保留在新布局 [0,10)；频点从旧 10 频点
变为新 15 频点——旧 prefs/用户 JSON 预设的 10 个增益值按频点位置**线性插值映射**到新
15 频点（log 频率轴插值），未覆盖段补 0。首启迁移一次（prefs 版本号标记）。

### 2.3 每段形态与系数平滑
- 每段 RBJ peaking biquad（与现状同款），级联 × 2 声道；
- freq/Q/gain 任一变化 → 目标系数重建 → **系数一阶平滑**（对 b0/b1/b2 线性插值若干帧
  或沿用增益斜坡思路对三个系数做 30ms 斜坡），杜绝拖动 freq/Q 时的 zipper/爆音；
- Q 上限 8.0（高 Q×高增益的振铃听感由用户自担，不强制限制组合）；
- 首版全部 peaking；lowshelf（首段）/highshelf（末段）留二期。

### 2.4 CPU 预算
15 段 × 2 声道 = 30 个 biquad（现状 20 个），每样本增量 ~10 biquad ≈ 可忽略
（对照 M8 多频段 240 flop/样本、DSP 单帧现状 0.27ms）。验收口径：装机 DSP 单帧
增量 < 0.05ms、长跑无 xRun。

## 3. 预设系统

- **内置 10 条**：平直 / 低音增强 / 低音减弱 / 流行 / 古典 / 人声 / 摇滚 / 电子 / 爵士 / 明亮。
  每条 = 完整 45 参快照（freq/Q 用默认值，增益给曲线形状）。
- **自定义**：用户当前 45 参快照存 JSON（复用现有 EffectPreset/用户预设体系，
  eq 参数块从 10 参扩 45 参，带格式版本号做迁移）。
- 应用预设 = 45 参全覆盖（含 freq/Q 归默认）；预设互通：图形页/专家页/预设同一数据源。

## 4. Kotlin/UI

- **图形页**：15 竖滑条墙（±12dB）+ 顶部频响曲线 Canvas；
- **专家页**：每段卡（freq/Q/gain 三滑条 + 实时数值），入口在图形页标题行切换；
- **频响曲线**：纯 Kotlin 合成（对每段 RBJ 二阶节在 log 频率轴采样 ~128 点求 dB 和），
  滑条拖动即时重绘，无引擎依赖、开销可忽略；
- 参数下发：走现有 PushCommand 通道（Kotlin EqParamIds 45 个，applyEqSettings 重放
  清单同步扩展）。

## 5. 实施分批

- **批 1（native + 桥）**：parametric_eq.hpp 15 段化 + freq/Q 参数 + 系数平滑 + 旧参迁移；
  Kotlin EqParamIds 45 参对齐；applyEqSettings 重放扩展；harness 用例（见 §6）。
- **批 2（UI 图形页）**：15 滑条墙 + 内置/自定义预设 + 频响曲线 Canvas + 旧预设迁移弹窗。
- **批 3（专家页）**：每段 freq/Q/gain 全参量 + 曲线联动 + 装机实听收口。

## 6. 验收标准

- harness：
  a) 15 段频响逐点验证（每频点 sine 扫频，实测增益 vs 设定 ±0.5dB）；
  b) freq/Q/gain 全参扫描（45 参极端值组合无 NaN/无爆音，系数平滑连续性断言）；
  c) bypass 逐位（A/B 标尺既有口径）；
  d) 旧 10 参迁移映射正确性断言（构造旧 prefs，断言插值结果）；
  e) 斜坡无爆音（参数跳变时样本级斜率断言，口径同 M8 9g）。
- 装机：
  a) DSP 单帧增量 < 0.05ms、满链长跑无 xRun；
  b) 滑条快速拖动/预设切换实听无毛刺（用户实听确认）；
  c) 频响曲线与听感一致（低音增强预设实听低频抬升明显）。

## 7. 风险与对策

- **旧预设频点漂移**：旧 10 频点与新 15 频点不同，迁移为近似映射——听感微移可接受，
  迁移弹窗一次性告知；
- **高 Q 振铃**：Q 上限 8.0，专家页给「复位该段」快捷；
- **45 参下发风暴**：滑条拖动经现有 PushCommand 合帧（复用参数斜坡底座）；
- **UI 曲线性能**：128 点 × 15 段合成 = 每帧 2k 乘加，Compose Canvas 毫秒级，无风险。

## 8. 明确不做（本期）

- 31 段、lowshelf/highshelf 段类型、左右独立 EQ、自动响度补偿（preset gain 自动配平）、
  频响实测曲线（需引测试信号，二期）。
