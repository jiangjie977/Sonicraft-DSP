⑤ 轻拟物五原则

1. 面 = 白→浅灰极缓渐变（≤4% 亮度差），不堆厚重立体；2. 顶部 inset 1px 白高光模拟受光（全局附加）；3. 阴影双层「近距锐+远距柔」，色相偏青与主色同族；4. 凹凸语义：可点击=凸（白面外阴影），容纳/展示=凹（灰面内阴影）；5. 主按钮/激活胶囊用对角渐变 #1C8C8C→#166B6B + 同色投影；旋钮/LED 遵循 Compose 已定稿参数（BlurMaskFilter 光晕，禁止 radialGradient 马赫带）。

⑥ 星云 AIOS 贴合规范（双强调分工）

系统气质对齐：轻盈干净、大留白、阴影克制（同层只保留 L1 基线）、动效「先快后慢」cubic-bezier(0.32,0.72,0,1) 250ms、按压 scale 0.98——不做花哨过渡。
双强调分工（杜绝两色打架）：星云渐变（紫蓝 #8A7EFF→#736FFA→科技蓝 #4797FE，对角 135°）= AI/系统层——引擎状态徽标、播放键、媒体封面、头像、AI 场景卡；青绿 #166B6B = 音频功能层——效果开关、激活胶囊、旋钮值弧、Tab 激活态（与 EQ 面板定稿一致）。
色值校准（2026-11-01 NX733J 真机像素采样完成）：紫蓝端取自「星云AI+」图标（#736FFA/#7F7CFA 实采），蓝端取自「AI 视频伪造检测」图标（#4797FE 实采）；系统功能激活蓝（控制中心卡 #169BF4→#0092F3）与系统纯灰中性面（#F5F5F5/#EBEBEB）均不采用——app 功能层保持青绿品牌、中性面保留青调轻拟物（EQ 定稿同源）；系统阴影几乎不可见（卡片靠底色对比分层），与本规范「同层只留 L1」方向一致。
