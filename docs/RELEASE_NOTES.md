# 发行说明

## v0.3.0 · 2026-11-14

> 本次最核心的变化：**AutoEq 从「改写你的 EQ」变成「独立的校正模块」**，
> 并补齐了 AutoEq 的四种导出格式与一个可管理的耳机曲线库。

产物：`app/build/outputs/apk/release/app-release.apk`
版本：`versionCode 8` / `versionName 0.3.0`
签名：`CN=Sonicraft, OU=jiangjie, O=jiangjie, C=CN`（SHA-256 `17b4a537…75e1a1`）

### 一、AutoEq 与均衡器解耦（行为变更）

此前导入 AutoEq 会**直接改写**参数均衡器的段值，带来三个问题：覆盖你手调的曲线、无法单独关闭、
与设备配置互相牵扯。0.3.0 起：

| 项 | 现在 |
|---|---|
| DSP | 新增**独立 AutoEq 节点**（PEQ 的第二实例，紧随其后串联） |
| 状态 | 独立的开关 + 独立的 31 段参数 + 独立的 preamp，键名 `auto_eq_*` |
| UI | 独立卡片，位于「均衡器」卡片下方，可单独折叠 |
| 导入 | **只写 AutoEq，不再触碰你的 PEQ** |

真机实测：导入 Sennheiser HD 600 后 `eq_bands_10` 与导入前**逐值相同**，
AutoEq 侧 `auto_eq_gains/types/qs/pregain` 与文件完全一致。

### 二、AutoEq 四种导出格式全部支持

| 文件 | 处理方式 |
|---|---|
| `… ParametricEQ.txt` | 逐段精确导入（PK/LSC/HSC + 频率 + 增益 + Q + preamp） |
| `… FixedBandEQ.txt` | 同上（Q 固定 1.41） |
| `… GraphicEQ.txt` | 频点曲线 → 按当前段频率映射，Q=1.41 |
| `… .csv` | 取 AutoEq 已算好的 `equalization` 列（缺失时回退 `error_smoothed` 取反） |

配套改进：

- **语法放宽**：`ON` 可省略、支持 `LS`/`HS`/`PEQ` 老写法、`S` 斜率不再被误当成 Q；
- **文件导入**：系统文件选择器选 `.txt/.csv`，正确读取真实文件名（此前会拿到文档 ID）；
- **先预览后应用**：选完文件先出频响曲线预览，确认后才生效；
- **跳过计数**：`LP`/`HP`/`None` 等本机不支持的段会明确提示「跳过 N 段」；
- **截断提示**：超出频率 20 Hz–20 kHz / 增益 ±12 dB / Q 0.3–8 的参数会被钳位，并提示「N 处超范围已截断」；
- **语境提示**：当前是扬声器输出时提醒「AutoEq 曲线为耳机设计，外放效果通常不佳」。

### 三、AutoEq 库（耳机曲线管理）

交互对齐「机架脚本库」：

- 导入成功**自动入库**，以文件名命名（同名覆盖）；
- 标题行计数 `库 · N/20 条`，可按标题折叠、限高滚动（约 3 行），**上限 20 条**，超出丢弃最旧；
- 每条左侧带**缩略频响曲线**，一眼认出是哪副耳机；
- 点按装载（只改 AutoEq）、「多选」批量删除、单条删除、「存当前入库」。

### 四、实际频响曲线

- 按段类型（PK/LSC/HSC）与每段 Q **精算**响应，随参数实时更新；
- 显示口径随开关切换：`PEQ + AutoEq`（两级串联，dB 相加）或 `仅 PEQ（AutoEq 关）`；
- 位于 AutoEq 卡片内，避免卡中卡。

### 五、设备配置跟随增强

切换耳机/扬声器时，现在会恢复**完整曲线**，不再只是几个快捷增益：

| 项 | 字段数 |
|---|---|
| 0.2.3 | 70 |
| 0.3.0 | **151**（EQ 逐段 30 键 + AutoEq 逐段 40 键 + 机架总闸 + 低频管家组闸等） |

- 新增**字符串段**：机架脚本文本（`script_src_N`）随设备保存与回放；
- 修复：`bass_gain`/`treble_gain` 快捷镜像会覆盖刚恢复的第 1/末段 —— 改为由实际段值派生。

### 六、界面规范化

- **全站可折叠卡片统一**：同一卡头组件、卡头高 56 dp、标题内边距 20 dp、内容内边距 20 dp；
- 卡头**整行可点**折叠（默认跟随开关：开则展开、关则收起），去掉按压涟漪；
- 「参量均衡」更名为「**均衡器**」，总开关从页头下沉到卡片标题行；
- 「收藏」页更名为「**预设与收藏**」，内置场景默认折叠，首屏优先展示你自己的组合；
- 修复展开态内容贴底（补 20 dp 底边距）；
- 旋钮过载红光改为呼吸式（周期 2400 ms）；虚拟低音参数改为五点梅花布局并与上方旋钮列对齐。

### 七、质量与工程

- 新增**设备配置覆盖守卫测试**：15 个效果器开关必须登记进快照且有回放分支（**无例外**），
  漏登记会直接让测试红；
- 新增 **AutoEq 真实文件回归**：ParametricEQ / FixedBandEQ / GraphicEQ / CSV 各有用例锁住格式兼容；
- 单元测试 **28 条全绿**，宿主侧 DSP 自检 `host-harness: ALL PASS`；
- CI：修复 `gradlew` 可执行位（Linux 上 `Permission denied`）、改用镜像自带 SDK。

### 升级说明

- **从 v0.2.3 升级**：同签名，覆盖安装即可，参数与设备配置保留；
- **从 debug 包升级**：debug 与 release 签名不同，需先卸载（**应用数据会被清除**）。

### 已知限制

- `GraphicEQ` / CSV 采用**定 Q（1.41）按段映射**，不是最小二乘拟合，与参数化导入相比会有细微差异；
- 卷积脉冲响应（`.wav`）导入尚未提供，属于卷积混响的功能线；
- AutoEq 曲线按耳机设计，扬声器上使用效果通常不佳（界面已有提示）。
