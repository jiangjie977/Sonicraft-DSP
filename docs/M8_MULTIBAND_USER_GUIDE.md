# 多频段压限器 使用说明书

> 适用版本：M8e（2026-10）。技术设计详见 `M8_MULTIBAND_LIMITER_DESIGN.md`。

## 一、这是什么

把全频带音乐按两个分频点切成**低 / 中 / 高三段**，每段各挂一个独立压缩器分别控制动态，最后合成回一路。相比单段压缩器「一声超阈全频压」的粗放，多频段只压超阈的那一段，其余频段原样通过——低音有力量、人声不塌、高频不闷可以同时成立。

信号链位置（与单段压缩器互斥，两者同时只生效一个）：

```
输入 → EQ(低音/高音) → 【多频段压限器 / 单段压缩器】→ 限幅器 → 输出增益 → 输出
```

- 分频用 **Linkwitz-Riley 4 阶（LR4）**：三段幅度合成严格平坦（实测 <0.03dB），分频点拖动实时平滑无爆音。
- 限幅器（−0.45dBFS）在多频段之后兜底峰值，多频段负责「整形」，限幅器负责「安全」，职责不重叠。

## 二、20 个滑块总表

每个频段（低 / 中 / 高）各有 6 个滑块，外加 2 个分频点，共 20 个。

### 分频点

| 滑块 | 范围 | 功能 |
|---|---|---|
| **低/中分频点 fc1** | 50~500 Hz | 低于此频率进低频段，此频率~fc2 进中频段。默认 200 Hz |
| **中/高分频点 fc2** | 1000~8000 Hz | fc1~此频率进中频段，高于此频率进高频段。默认 3500 Hz |

### 每段 6 参（低/中/高各一套）

| 滑块 | 范围 | 单位 | 功能 |
|---|---|---|---|
| **阈值** | −60 ~ 0 | dBFS | 该段信号电平超过它才开始压缩。**决定「压多少」的第一旋钮** |
| **压缩比** | 1 ~ 20 | :1 | 超阈部分被压的程度。2:1 = 超出 2dB 只留 1dB；20:1 ≈ 限幅 |
| **启动** | 0.1 ~ 100 | ms | 超阈后压缩多快到位。越短压得越狠、越吃瞬态冲击头 |
| **释放** | 5 ~ 1000 | ms | 回落后压缩多快松开。太短有「抽吸/POPO 泵感」，太长声音发闷滞后 |
| **拐点(软膝)** | 0 ~ 12 | dB | 阈值附近的过渡柔和度。0=硬膝（到点就压），6dB 左右过渡自然几乎听不出动作 |
| **段增益** | −12 ~ +12 | dB | 该段压缩**之后**的响度补偿（makeup）。不改变压缩量，只加减该段音量 |

> **段增益注意**：它是压缩后补偿——先按检测信号算好压缩量，再把段增益加在输出上。想「多压一点但别变小声」就用它补回来；但它不会让压缩器「多动作」。

## 三、每个滑块怎么调（机理 + 手感）

### 阈值 —— 「让谁进压缩区」
- 抬高 → 更少信号被压 → 更保真、更有力量（峰值安全网式）
- 降低 → 更多信号被压 → 更平顺、更响，但动作痕迹风险大
- **DJ/电音低频**的推荐思路是高阈值（−11~−3dBFS）：只在 kick/808 极端峰值动作，低音长音原样通过，力量感最大化。持续压缩式（−20dB 级）会把低音压闷。
- **人声歌中频**同理：阈值太低（如 −22dB）会让抒情歌人声电平常驻压缩区被持续压着 → 「人声弱」。−10dB 左右只控制失控峰值。

### 压缩比 —— 「压多狠」
- 1.5~3:1：音乐性压缩，平顺动态，几乎无痕迹（中/高频段常用）
- 4~6:1：明显控制（低频 kick 峰值、防失真）
- 10~20:1：接近限幅，只在「绝不许超」的场合用
- 比例与阈值联动：高阈值 + 中比例 = 偶尔动作；低阈值 + 高比例 = 持续整形（响但闷）

### 启动 —— 「瞬态保多少」
- 低频段：10ms 左右故意放 kick 冲击头进来（保「力」），20ms 以上冲击更凸出但可能顶限幅器
- 中频段：15ms 保留人声辅音起始（咬字清晰）；<5ms 会吃掉冲击力使人声变钝
- 高频段：3~5ms（镲片瞬态短，慢启动会漏压尖峰）

### 释放 —— 「松开自然不自然」
- **泵感（POPO/抽吸）**= 释放太短，下一击还没来压缩就松完了 → 加长（150ms 起）
- **发闷/拖泥带水** = 释放太长，压缩还挂着新内容已到 → 缩短
- 100~200ms 是大多数曲风的舒适区；节奏快的电子乐可略短（100~150ms），慢歌可略长

### 拐点 —— 「动作听不听得出」
- 0（硬膝）：控制精准但过阈瞬间有可闻「掐」感
- 6dB：通用推荐，阈值附近渐进进入压缩，无痕
- 12dB：极度柔顺，但控制精度下降（轻微超阈就开始压）

### 段增益 —— 「该段响度补偿」
- 压缩会让该段整体变轻，用段增益补回
- 也当「频段音量微调」用：人声不够凸出（150~3000Hz 在中频段）可 +1~+2dB——但注意它也抬高了进限幅器的电平，配合输出增益别把余量吃光

### 分频点 —— 「切在哪」
- 经典三带：**fc1=150~200 / fc2=3000~3500**（sub/低音舞曲元素 ｜ 人声与主体 ｜ 亮度齿音）
- fc1 过低（<120Hz）：中频段会混入 kick 底能，人声压缩误伤低音
- fc2 过低（<2500Hz）：人声齿音区被拉进高频段，高频压缩可能压掉「嘶」声细节；过高（>5kHz）则镲片失控风险进中频段
- 拖动实时生效（系数平滑无爆音），可边放歌边找切点

## 四、建议参数值

### 预设 A：电音 / DJ（真机实听定案，力量优先）

| 段 | 阈值 | 比例 | 启动 | 释放 | 拐点 | 段增益 |
|---|---|---|---|---|---|---|
| Low | **−3.0** | 4.0 | 10 | 150 | 6 | 0 |
| Mid | **−10.0** | 2.5 | 15 | 150 | 6 | 0 ~ +1.5 |
| High | **−20** | 2.0 | 5 | 120 | 6 | 0 |
| fc | **154 / 3331 Hz** | | | | | |

思路：低频「峰值安全网」——只 kick 峰值动作，力量全保；中频轻控人声失控段；高频防镲片炸。三段压缩活动都少，声音干净有冲击。**实测曲风：DJ 舞曲、电音、流行**。

### 预设 B：全曲平滑（响度优先）

| 段 | 阈值 | 比例 | 启动 | 释放 | 拐点 | 段增益 |
|---|---|---|---|---|---|---|
| Low | −18 | 2.5 | 20 | 200 | 6 | +1 |
| Mid | −18 | 2.0 | 10 | 150 | 6 | +1 |
| High | −24 | 2.0 | 3 | 100 | 6 | 0 |
| fc | 200 / 3500 Hz | | | | | |

思路：三段都持续温和整形，整体响度感明显更大、更「平」，代价是低音冲击力与动态被削一部分。适合背景音乐、播客伴奏、响度竞争强的流媒体源。

### 预设 C：透明保险（几乎不动声）

| 段 | 阈值 | 比例 | 启动 | 释放 | 拐点 | 段增益 |
|---|---|---|---|---|---|---|
| Low | −8 | 2.0 | 5 | 100 | 6 | 0 |
| Mid | −12 | 1.5 | 15 | 150 | 6 | 0 |
| High | −15 | 1.5 | 5 | 100 | 6 | 0 |
| fc | 200 / 3500 Hz | | | | | |

思路：只兜极端峰值，动态原味保留。适合听音质本身很好的源（无损、精制母带），多频段存在感最低。

## 五、常见症状速查

| 症状 | 原因 | 动哪 |
|---|---|---|
| 低音发闷没力量 | 低频段阈值过低持续压缩 | Low 阈值 −20 级 → 抬到 −11~−3 |
| 低音「POPO」泵感 | Low 释放太短 | Low 释放 50ms 级 → 加到 150ms+ |
| 人声忽响忽轻（抽吸） | Mid 阈值低 + 释放短 | Mid 阈值抬 + 释放 ≥150ms |
| 人声弱/被压塌 | Mid 持续压缩（抒情歌电平常驻阈上） | Mid 阈值 −22 → −10 左右 |
| 齿音「嘶嘶」刺耳 | High 段压缩放过了尖峰 | High 阈值降低或比例加大；先查 EQ 高音是否推太高 |
| 镲片忽明忽暗 | High 释放太短泵感 | High 释放加长（100~150ms） |
| 拖分频点爆音 | ——（不该出现） | 已由系数逐样本平滑消除；若复现请反馈 |
| 整体变响但糊 | 预设 B 类持续整形过度 | 各段阈值整体抬高，回归预设 A/C |

## 六、调参顺序（黄金法则）

1. **先定分频点**（150~200 / 3000~3500 起步，按曲风微调）
2. **逐段定阈值**：放典型曲目，看症状抬/降——先保「不压缩时声音对」
3. **再定比例**：动作量不够加大比例，别急着降阈值
4. **后定时间**：出现泵感加释放；冲击头被吃加启动
5. **最后段增益**：只补响度差，+3dB 以上说明阈值/比例该重调了
6. 每次只动一个滑块，A/B 对比（音效总开关切「A/B 标尺」）
